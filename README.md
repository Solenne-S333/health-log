# Health Log

A private, offline personal health tracker — a single-page web app.

**This repository contains only the app's code. It holds no personal data.**
All health data lives in the user's own browser storage (and, optionally, their own
cloud drive) — never in this repo.

- `index.html` — the whole app (logging, history, trends, doctor summary)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — make it installable and offline-capable

Served as a static site via GitHub Pages.
